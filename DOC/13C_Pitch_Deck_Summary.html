Apa itu 13C?

Infrastruktur payment gateway berbasis cryptocurrency untuk toko online/merchant, yang memungkinkan penerimaan pembayaran kripto (USDT/USDC) dengan arsitektur non-custodial.

💡 100% Self-Hosted & Non-Custodial Direct-to-Wallet
Konsep Utama
  • Non-Custodial: Dana tidak pernah disimpan di pihak gateway perantara.
  • Instant Forwarding: Pembayaran langsung diteruskan ke Cold Wallet pribadi merchant.
  • Aman & Transparan: Didukung multi-chain berbiaya rendah dan zero holding pool.

Siklus Tagihan (Invoice)
  1. Keypair Baru: Pembuatan keypair independen per invoice (ECDSA EVM/TRON, Ed25519 Solana).
  2. Enkripsi Militer: Private key dienkripsi dengan AES-256-GCM sebelum disimpan ke DB.
  3. Masa Berlaku: Kedaluwarsa 15–30 menit; jika lewat, alamat otomatis dinonaktifkan.

Keamanan Sistem
  • API Key disimpan dalam bentuk hash SHA-256.
  • Private key ephemeral dienkripsi AES-256-GCM.
  • Webhook terlindungi signature HMAC-SHA256.
  • Proteksi SSRF link-local & private IP.
  • Two-Factor Authentication (2FA TOTP Google Authenticator) pada penarikan dana.
  • Dana langsung ke Cold Wallet pribadi merchant.
🎯 Kesimpulan

13C adalah crypto payment gateway non-custodial yang memungkinkan merchant menerima pembayaran USDT/USDC di 4 jaringan blockchain, dengan proses aman, cepat, dan terintegrasi melalui API serta dashboard lengkap. Sangat cocok untuk platform/marketplace yang ingin kedaulatan pembayaran kripto langsung ke wallet pribadi.

⭐ Keunggulan Utama
  • Mendukung 4 jaringan blockchain tercepat & termurah.
  • Setiap invoice memiliki alamat deposit tersendiri.
  • Dana langsung disapu ke wallet pribadi merchant.
  • Tersedia REST API dan widget checkout responsif.
  • Dashboard lengkap dengan laporan keuangan & webhook logs.
⚠️ Hal yang Perlu Diperhatikan
  • Amankan private key master dan kredensial server.
  • Uji transaksi end-to-end di testnet/sandbox sebelum rilis.
  • Pantau cadangan saldo gas Hot Wallet untuk proses sweep.
  • Patuhi regulasi dan aspek legalitas lokal wilayah bisnis Anda.
